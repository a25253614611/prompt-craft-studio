# 提示詞工坊

將簡短想法整理成完整提示詞的繁體中文網頁工具。輸入任務後，工具會推測類型、顯示六個可選補問，並產生可編輯、複製及下載的 Markdown 提示詞。使用者勾選後，最近使用紀錄才會存入此瀏覽器的 localStorage。

## 本機使用

在 `dist` 目錄啟動任何靜態 HTTP 伺服器即可。核心邏輯可用 `node test.mjs` 驗證，無須安裝套件。

## 邊界

本頁使用本機規則整理內容，不呼叫生成式 AI，也不把使用者的輸入上傳。它不會推論未提供的專業事實；缺少重要條件時，產出的提示詞會要求接收它的 AI 先提問。任務類型判斷使用關鍵字，使用者可手動調整。
