# 提示詞工坊

將簡短想法整理成提示詞的繁體中文網頁工具。輸入任務後，工具會推測類型並提出最多 3 個問題；問題從交付成果、可用資訊和會改變做法的條件出發。缺少決定方向的目的或資料時，該題必答；其餘可留空。例如新程式詢問功能、修錯詢問症狀、整理電腦先詢問目的。產品分析會先確認要交付範圍評估、驗收標準、功能規格或分期規劃，再把原文的第一版與後續功能轉成可檢查的要求。產出可編輯、複製及下載。使用者勾選後，最近使用紀錄才會存入此瀏覽器的 localStorage。

## 本機使用

在 `dist` 目錄啟動任何靜態 HTTP 伺服器即可。核心邏輯可用 `node test.mjs` 驗證，無須安裝套件。

## 邊界

本頁使用本機規則整理內容，不呼叫生成式 AI，也不把使用者的輸入上傳。它不會推論未提供的專業事實；未涵蓋的模糊需求仍可能需要使用者補充。任務類型判斷使用關鍵字，使用者可手動調整。改寫需求後會清除上一題的補問答案與產出，避免混入新提示詞。
